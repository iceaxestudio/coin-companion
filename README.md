# Coin Companion

Open https://iceaxestudio.github.io/coin-companion/ in Safari, then Share → Add to Home Screen.

Balances, stakes and timers are saved locally on each device; they do not sync between Android and iPhone. The /coins shortcut copies the command and opens Discord. Submit all commands manually.

The web version does not deliver background cooldown notifications. Android provides local reminders. No Discord login or gameplay automation.
